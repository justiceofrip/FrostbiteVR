# Checkpoint264 player check

Local development candidate, not a release. Consult RECOVERY-264.md and
ACTIVE-WORK.json for validation and launch readiness. Use a fresh BC2 process
and a staged player build with no emulated input driver.

1. Holster the SPAS, lower both hands and squeeze the right grip. Hands should
   stay empty until a shoulder grab. Repeat after a brief tracking interruption.
2. Draw the SCAR, acquire and release its front grip, and reload the magazine.
3. Draw the SPAS, aim with both hands and fire. Pump back and forward naturally,
   without pauses at either end. Confirm another shot, including at another angle.
4. Insert a shell through the bottom port. Keep squeezing and return immediately
   to the fore-end; the support grip should return without the old delay.
5. Swap shoulders, reload the rifle and confirm firing still works.

Actual-game emulation verifies input, hand ownership and native ammunition
receipts. Hand placement, comfort and visuals still need headset feedback.
SCAR/SPAS and F2000/SPAS passed the same264 combined game sequence with the same
frozen code, including immediate support return at about134ms. Twelve exact
support configurations share six measured anchors; this is not whole-roster
acceptance. Earlier M95 bolt evidence is retained from258.

Campaign checkpoint/death reload crashing remains unresolved. Pistol and
belt-fed mechanisms are not newly enabled. GitHub remains245. Leave the player
session running until the user finishes, then end only the mod when authorized.
