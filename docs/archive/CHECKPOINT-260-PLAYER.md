# Checkpoint260 player check

Local development candidate; latest headset258 failed. Read RECOVERY-260.md and
ACTIVE-WORK.json for current validation and exact launch readiness. A staged
player build must have no emulated input driver and must use a fresh BC2 process.

1. Holster the SPAS and squeeze the right grip with hands lowered. Stay empty;
   only reaching a shoulder and grabbing should draw a gun. Repeat after a brief
   headset tracking interruption.
2. Draw the SCAR, acquire/release its front support grip and reload its magazine.
   Check hand placement and firing after seating the magazine.
3. Draw the SPAS and aim with both hands. Fire, then pump fully back and forward
   without pausing at either end. Try another gun angle. Confirm the next shot.
4. Insert a shell through the bottom port, keep squeezing and move straight back
   to the fore-end. The support grip should return without the old delay.
5. Swap shoulders, reload the rifle again, and verify normal firing. If practical,
   briefly interrupt tracking mid-pump and complete the stroke after returning.

Actual-game emulation verifies input, hand custody and native ammunition
receipts. Headset hand placement, feel and visuals remain separate. The new
support-only registry covers twelve exact configurations through six measured
anchors; this is not headset acceptance of all weapons. The earlier M95 native
bolt tests are retained evidence from258, not a new260 bolt test.

Campaign checkpoint/death reload crashing remains unresolved. Pistol and
belt-fed mechanics are not newly enabled. GitHub remains245.

Leave a player session running until the user finishes; end only the mod when
authorized, preserving BC2 and SteamVR unless a fresh game is requested.
