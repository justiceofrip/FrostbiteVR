## Earlier 206 headset checklist

Use one representative rifle first, normally the XM8, plus the SPAS. Include AEK
only if it is already available; there is no need to search for every batch gun.

| Step | Action | Expected result |
| --- | --- | --- |
| 1 | Remove a partly used rifle magazine and put that same magazine back; repeat, then insert a chest replacement | Reliable grab, retained original ammunition, visible rail guidance and one completed transfer |
| 2 | Empty the rifle while holding it with one hand, then with support grip | Manual reload stays required; no unattended native reload or disappearing-magazine sequence |
| 3 | Immediately grip the fore-end after insertion | Support grip responds without the old multi-second lockout |
| 4 | Stow/draw from both shoulders and swap several times; then repeat a reload | Predictable assignments, no spontaneous draw, and magazine/shell supply still available |
| 5 | Insert SPAS shells after a weapon swap | Shell spawns at the body and loads through the bottom feed; manual pumping is not part of this build |
| 6 | Briefly interrupt tracking, reconnect and recenter; then repeat a simple reload | Correct body/hand alignment and fresh interactions; no stuck ownership from the old session |
| Optional transition | If the boat/pickup is already nearby, exit the seat or pick up while empty-handed, then reload | Empty-hand behavior and supply remain usable; no need for a new weapon-calibration exercise |

Report the first failure with the action immediately before it, whether the gun
was empty, whether support grip was held, and whether a swap/holster/vehicle or
tracking transition had occurred. A short video remains useful for pose and
animation failures. The mod session stays up until the user finishes it.

This headset check does not include newly enabled LMG/pistol/sniper mechanisms,
manual pumping, manual launcher reloads, full-body IK or multiplayer. After the
shared regression passes, the next implementation step is batch native/package
integration for the compatible magazine family.
