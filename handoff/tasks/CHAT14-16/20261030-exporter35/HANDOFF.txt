CLI: python tools/bc2_mechanism_registry_header.py --jobs <existing descriptor-jobs.json> --reviewed <existing native-review-list.json> --annotations <reviewed-annotations.json> --evidence-root <pinned JSON root> --feed-header <private Feed.h> --pistol-header <private Slide.h> --receipt <receipt.json> [--admissions <mechanism-admissions.json>].
No real enrollment data or generated production header is invented. Sources are existing pipeline/measured JSON, read once as bounded bytes and SHA256 pinned. Synthetic configurations exist only in the test file.
Annotations schema fvr.bc2.mechanism_registry_annotations.v1: sources{id:{path,sha256}}, profiles[]. Paths are canonical relative paths; hashes bind consumed bytes. Geometry/rig/selector measurements use {source,pointer} JSON references, optionally assembled into named members. Literal measured scalars are refused.
Exact anchor geometry_evidence must carry its own configuration resource/GUID/hash, asset, mesh and rig. mechanisms.json rows and existing exact measurement shapes are supported through shared field aliases. All pointer ancestors carrying identities are checked too. M60 proof01 frames can supply measurements but need their original exact configuration/geometry record as anchor because the frames proof alone lacks config GUID/hash.
Explicit reviewed roles: feed root/pouch/cover/feed_chain[1..8]; slide root/slide. Root={bone,index}; children={bone,index,parent,parentIndex}. Actual topology, unique bone/index roles and active pose chain counts are checked. No labels, weapon names or sampled curves infer roles.
Resolved feed geometry matches public Bc2FeedGeometry fields; seven pose slots are explicit, chainCount comes from reviewed active chain. Pistol geometry matches public Bc2PistolSlideGeometry measured fields. Native closed/retracted/controller-grasp flags remain false; unknown attempted claims are rejected.
VR policy is literal reviewed data, separate from authored geometry. Current feed requirement class permits only cover/container coupled same-container replenishment; latch/charge/separate-withdrawal assumptions are refused. Pistol policy must fit signed measured extrema and current recognizer bounds.
Existing bc2_magazine_registry_header.build validates native descriptor identity/digest/timing/family proof unchanged. Supported classes are wcLmg AutomaticMagazineZeroBoltTransfer and wcPistol SingleFireMagazineZeroBolt; class alone never grants admission.
Mechanism profileDigest includes kind, exact native key/digest/config, exact selection, resolved geometry/roles, VR policy, mechanism requirements and evidence provenance. key=first16hex(profileDigest), distinct from native magazine key. Enabled/reviewed grants are excluded from the digest being reviewed.
Separate admission document fvr.bc2.mechanism_admission_reviews.v1 binds profile_digest+descriptor_key+descriptor_digest+native_class with explicit physical_reviewed/native_reviewed, reviewer and pinned evidence reference. Existing native descriptor review is independently mandatory. Missing admission emits a disabled candidate; requested enablement without it rejects the row. Changed policy/geometry invalidates an old admission digest.
Output uses named C++ assignments and immutable fvr::bc2::generated::GeneratedFeedProfiles / GeneratedPistolSlideProfiles arrays, with family-specific symbol prefixes and headers for the two private registry translation units. No CMake normal feature flags or builtins changed by this agent.
Receipt separates requested/emitted/enabled/rejected counts and per-row missing prerequisites. Any rejected row makes the batch invalid; CLI writes the diagnostic receipt, exits2, and writes neither header. Global identity/hash/review errors raise ValueError before output. Existing headers are never silently replaced by an invalid batch; callers must honor exit status and current receipt.
