The shared firing adapter changes the caller's absolute projectile origin once
per whole shot, after native spawn-route selection. It preserves the caller's
pointer, velocity, matrix basis, subsequent projectile effects and native writes.
It does not restore the old origin after native firing. A partially failed write
must restore its exact original bytes before forwarding; unresolved corruption
is reported as an adapter failure instead of forwarding corrupted input.

lifetimes and exact compiled weapon/part metadata to the final displayed exit.

consistent. The correction requires a separate compiled capability and explicit
fixed marker; ordinary installation does not silently enable the candidate.
